# HASNAIN KHAN — Students' Wellness Hub

## Implementation approach

A plain static website built with semantic HTML, modern CSS, and vanilla JavaScript so it can be uploaded directly to GitHub Pages. No build step or backend is required. Interactions are intentionally lightweight and client-side: smooth navigation, an accessible mobile menu, a four-question wellness check-in, a breathing exercise timer, accordion-style guidance, and a resource filter.

## Required assignment coverage

- Theme: Mental Health Matters: Students' Wellness Hub.
- Full name shown on the website: HASNAIN KHAN.
- UTHM and FSKTM logos included in the header and footer.
- Educational resources, real-support guidance, community ideas, helplines, and wellness initiatives.
- Public-hosting-ready files for GitHub Pages.

## Design direction

- **Design movement:** Editorial wellness interface with soft neo-brutalist cards and calm editorial spacing.
- **Core principles:** Warm but not childish; clear before clever; supportive without being clinical; accessible at every screen size.
- **Color philosophy:** Deep ink/navy creates trust, mint and coral add human warmth, and cream keeps the page breathable. Coral is reserved for urgent support and key calls to action.
- **Layout paradigm:** A scrollable editorial story with a bold split hero, staggered content bands, and a persistent support rail rather than a generic centered grid.
- **Signature elements:** Oversized rounded number labels, thin hand-drawn-style line accents, and a small floating “you matter” note.
- **Interaction philosophy:** Small, reversible interactions that encourage reflection without collecting personal data.
- **Animation:** Gentle fade/slide-on-scroll and breathing expansion only; respects `prefers-reduced-motion`.
- **Typography:** Space Grotesk for headlines and DM Sans for body copy; high contrast and generous line height.
- **Brand essence:** A student-first reset space that helps UTHM learners notice what they need, find support, and take one kind next step. Personality: grounded, hopeful, practical.
- **Brand voice:** Direct, human, and non-judgmental. Example lines: “You do not have to solve everything today.” / “Start small. Reach out early.”
- **Wordmark:** The “MHM” monogram uses a heart-like central notch in a rounded square mark.
- **Signature brand color:** `#9BE8C9` mint, used as the ownable calm signal throughout the interface.

## Project structure

- `index.html` — all page sections and accessible content.
- `styles.css` — responsive visual system, layout, components, and reduced-motion rules.
- `script.js` — menu, check-in, breathing timer, accordion, filters, and current year.
- `assets/uthm-logo.png` — UTHM logo asset.
- `assets/fsktm-logo.png` — FSKTM logo asset.
- `README.md` — GitHub Pages publishing instructions and content/source notes.
